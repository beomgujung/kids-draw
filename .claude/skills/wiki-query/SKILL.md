# wiki-query

1. `wiki/index.md`를 읽고 관련 페이지를 고른다. 필요하면 `grep -ri`로 wiki/ 전체를 검색한다.
2. 관련 페이지를 읽고, 링크를 따라 한 단계 더 들어간다. 근거가 부족할 때만 `raw/` 원문을 확인한다.
3. 답변은 출처 페이지를 `[[...]]`로 인용한다. 위키에 없는 내용은 "위키에 근거 없음"이라고 명시하고, 일반 지식/추측과 구분한다.
4. 답이 비교표, 종합 분석, 새로운 연결처럼 다시 쓸 가치가 있으면 `wiki/research/` 또는 적절한 폴더에 페이지로 저장할지 묻는다(동의 시 저장 + index.md 갱신).
5. `wiki/log.md`에 append:
   ```
   ## [YYYY-MM-DD] query | <질문 요약>
   - 참고: [[...]]; 저장: [[...]] (있으면)
   ```
6. 답하면서 발견한 빈틈(필요한데 없는 페이지, 상충)은 마지막에 한 줄로 알려준다.
